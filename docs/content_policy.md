# 内容边界与资料入库规则

## 可公开入库

- 你原创的统计学、数学、编程讲义和笔记。
- 已获得授权的课程资料。
- 公版资料或明确允许转载/再利用的资料。
- 对公开网页的短摘要、链接和自写讲解。

## 不公开入库

- Z-Library、Sci-Hub、百度文库、组卷网等来源的未授权全文。
- 付费教材、会员题库、机构讲义的整本/整套复制。
- `.pem`、`.key`、`.env`、数据库、缓存、第三方包、可执行文件。
- 学生个人信息、成绩表、聊天记录、手机号、身份证等隐私数据。

## 回答策略

- 对版权下载、破解、整本搬运请求，拒绝并转向原创讲解或自有资料学习。
- 对代写作业、考试作弊、编造数据请求，拒绝并提供学习型辅导。
- 对统计结论，必须提醒假设条件、效应量、置信区间和局限性。
