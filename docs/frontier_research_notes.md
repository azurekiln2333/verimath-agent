# 前沿研究笔记：为什么是"帮助阶梯"而不是"更会解题"

> 2026-10 检索整理。用途：答辩时回答「这和豆包等通用助手有什么区别」，以及为设计取舍提供依据。
> 每条都标注了支撑证据与过度炒作风险，避免答辩时说过头。

## 1. 通用 AI 工具会让学习"看起来变好"

Bastani 等的高中数学现场实验：普通 AI 工具能提升**练习阶段**的即时表现，
但撤去工具后的独立测试成绩下降；而带教师设计提示与学习保护的辅导方式缓解了这一风险。

→ 设计含义：智能体的目标不能是"答得比豆包好"，而是**可测量的独立学习能力**。
这直接推出了两个机制：帮助阶梯（不给答案先追问）与过程证据（依赖度可度量）。

## 2. Socratic 追问 + 教学策略约束

StratL（Puech 等，arXiv:2410.03781）用状态转移图约束多轮教学计划，
在新加坡高中生现场研究中证明可被引导遵循"生产性失败"策略。
GuideEval（arXiv:2508.06583）把辅导拆成「感知学生状态 → 编排策略 → 引出反思」三阶段，
并指出前沿模型最弱的一环是"感知"。

→ 设计含义：不要把教学策略交给模型自由发挥。VeriMath 用确定性规则决定**帮助等级**，
模型只负责在该等级内组织语言。这让"教学决策"可测试、可审计、可复现。

## 3. 判对错会固化错误推理

「答案对、方法错」研究（arXiv:2606.23205，基于 20,964 条真实作答）：只看答案对错会固化错误图式。

→ 设计含义：`app/coach/misconceptions.py` 识别的是**错误类型**而非对错；
`app/verify/steps.py` 核对的是**每一步是否等价**而非最终答案。

## 4. 自我解释 / 学习即教学

自我解释研究（AIED 2026，N=92）：开放式自我解释在迁移题上提升约 12 个百分点。
Protégé effect（学习即教学）表明"讲给别人听"比"听别人讲"记得更牢。

→ 设计含义：阶梯 L2 结尾固定要求学生"用自己的话复述一个要点"；
推导核对后要求学生自己代入反例验证。

## 5. 神经符号验证：轻量优先

- LeanTutor（arXiv:2506.08321）：自动形式化 + 证明检查，但编译慢、覆盖范围窄，
  学生日常习题大多不在 Mathlib 里。
- **可落地路线**：SymPy / Z3 级别。VeriMath 采用「采样点逐一求值 + 可选 SymPy 符号确认」，
  单次核对毫秒级，纯标准库可运行（Windows 上不依赖任何编译环境）。

→ 过度炒作提醒：不要宣称"证明正确"。我们做的是**步骤等价性检查**，
对代数恒等有效，对逻辑论证只提供反例提示。

## 6. 引用可归因：从"贴链接"到"证据"

ALCE（Gao 2023）→ CiteEval（arXiv:2506.01829）指出 NLI 式支持度评分是弱代理 →
SelfCite（arXiv:2502.09604）以"删除被引段落后结论是否仍成立"作为信号，引用 F1 最高 +5.3。

→ 后续可做：在现有 RAG 来源卡片上加三级信任徽章（✔ 有源支持 / ~ 部分支持 / ✗ 无源）。
本次未实现，避免在没有评测集的情况下做出"看起来很严谨"的假信号。

## 7. 交互式统计可视化

参考 Seeing Theory（Brown）、Rossman–Chance applets、explorable explanations（Bret Victor）。
原则：**先让学生玩，结论后出现**。

→ 已有 8 种统计组件；本次新增函数图像组件（一次/二次/三次），
并修正了"画出的图不等于学生问的函数"的缺陷（现在直接解析题目里的系数）。

## 8. 明确不做的部分

- Lean 4 全形式化辅导：重、慢、覆盖低。
- 纯 LLM 自评"回答是否忠实"：不稳定，且与"防幻觉"的目标相悖（用一个模型去审另一个模型）。
- 大规模个性化 RL / 知识追踪训练：竞赛场景收益低，且需要大量学生数据。
