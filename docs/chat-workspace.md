# 聊天工作区

对话是主入口。完整回答结束后提出可视化候选，用户点击才创建后台任务。生成期间可以继续聊天，完成结果内嵌于原回答，不改变输入焦点或主动滚动页面。

## 界面与状态

- 左栏为新对话、会话搜索、历史和设置；学习功能集中在右侧工具面板。
- 输入区上方写问题，底部“＋”只负责添加图片；拍照识题有文字入口，发送与停止固定在右下角。欢迎页提供概念、拍照、可视化三个入口。
- 正文和输入框共用 760px 阅读宽度。桌面聊天区至少保留 640px；空间不足时工具覆盖展开，小于 1024px 时左栏也改为抽屉。
- 右侧正文采用系统宋体字体栈，按钮保留界面字体。公式用数学排版，真正的程序代码保留代码块。
- 会话消息、可视化候选、任务与结果存于 SQLite。草稿、阅读位置和图表参数存于当前浏览器。
- 内嵌 Canvas 可收起、放大及导出。放大复用原组件；iframe 用单一内容尺寸协议，最长占视口高度的 70%，内部可滚动。

## 后端约定

| 接口 | 用途 |
| --- | --- |
| `GET /api/panel/sessions` | 完整会话列表 |
| `GET /api/panel/sessions/{session_id}/messages` | 消息及候选、任务恢复；支持 `before`、`limit` |
| `POST /api/panel/chat/stream` | 流式回答；`meta` 携带消息标识，`final` 在回答持久化后发送 |
| `GET /api/panel/artifact-jobs?session_id=...` | 当前会话候选及任务状态 |
| `POST /api/panel/artifact-jobs` | 立即返回 `job_id`；请求包含会话、消息、候选标识 |
| `POST /api/panel/artifact-jobs/{job_id}/cancel` | 独立取消可视化任务 |
| `POST /api/panel/sessions/{session_id}/messages/{message_id}/recommendations` | 重新生成对应回答的追问建议 |
| `POST /api/coach/ocr` | 识别题目图片，返回可编辑文本与分类 |

重复点击复用同一个任务。取消、失败、中断或已生成的画布运行异常时，携带当前任务的 `retry_of` 创建新尝试，同一重试请求仍去重。前端仅在候选判断或生成未结束时每两秒同步，恢复网络后重新同步。

追问推荐读取本轮完整回答与此前对话，由模型提出候选并独立审查，过滤重复、已回答或偏题问题。状态覆盖整理、审查、完成、失败和中断，排队加生成有总时限；没有有价值的追问时允许留空。点击推荐会发送带会话上下文的新聊天请求。重试建议不影响聊天或画布。

OCR 支持上传、手机拍照、粘贴和拖放 PNG/JPEG/WebP/GIF 图片，单张最多 8 MB。识别结果先显示图片、排版后的公式和可编辑文字，经确认后追加到现有草稿。识别任务绑定开始时的会话，切换会话或主动取消会中止请求，迟到响应不会串入新草稿。图片发送至已配置的模型服务，应用不保存原图；脱敏识别文本在本地归档。

OCR 复用模型连接池，并发上限为 2，排队与请求合计最多 75 秒。私有 `.env` 中的 `OCR_MODEL_NAME` 可指定同一 API 服务上的视觉模型；留空使用聊天模型，所选模型必须支持图像输入。识别失败不会自动把不完整文本放入聊天。

首版采用**单个应用进程、单个 Canvas 工作任务**，其他画布排队，聊天与候选判断独立运行。启动命令使用默认单进程，不配置多个 Uvicorn workers。浏览器刷新不会取消画布；服务重启后未完成任务标记为中断，允许重试。

旧 `interactions` 记录幂等导入新增消息表，原表和原有 A2A 接口保留。回退版本时可继续读取原日志，无需删除新表。
旧版本未写入日志的画布结果无法追溯恢复；新版任务从创建起保存完整结果。

## 验证

```sh
python -m pytest -q
python -m pip install -e ".[browser]"
python -m playwright install chromium
python tests/browser_regression.py --output build/chat-regression
```

浏览器回归启动临时数据库和隔离服务，使用确定性图表、受控慢任务和合成图片，不调用外部模型。覆盖六档窗口、拖动和抽屉、并发聊天、刷新与会话切换、断网恢复、取消与重试、参数与尺寸、数学排版和导出；另测 OCR 草稿保护与迟到响应、追问轮询去重，以及画布脚本出错后的真正重新生成。截图及几何检查保存在输出目录。

自定义 Canvas 先校验文档闭合与大小；截断输出最多进行一次精简重生成，网络错误不盲目重复调用。运行时使用隔离 iframe、内容安全策略和提前注入的桥接脚本，禁止外部资源，捕获早期脚本错误与未就绪状态。历史画布返回浏览器时更新桥接协议，不修改数据库中的原始结果。

数学工具新增 `calculate_calculus(operation="evaluate")`，复用现有受限计算进程完成展开、简化和指定点代入。工具结果明确说明只核对了哪个表达式、哪些坐标，符号展开不会给其他数值例子背书。模型生成的解释与自定义图形仍可能有语义错误；结构通过、运行正常和数学正确是不同的验收条件。
